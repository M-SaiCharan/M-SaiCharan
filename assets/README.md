# Artwork notes

- header.svg, process.svg and portfolio.svg are custom vector layouts for this profile.
- The header uses a custom mathematical wireframe landscape, with no portrait or embedded raster image. The process strip connects visual input, perception and software.
- Display lettering uses Anton, matching the portfolio. Its outlines are embedded for consistent rendering; see FONT-LICENSE.txt.
- Small lettering uses DejaVu Sans and DejaVu Sans Mono outlines; see DEJAVU-LICENSE.txt.
- The designs use the portfolio palette: #0e0e0e, #ececec, and #ff3838.
- All SVGs are static and contain no scripts or external font requests.
